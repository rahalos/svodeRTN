# Модульная (оптимизированная) версия обработки Excel-отчётов КОАП

## Установка и запуск

1. Установите зависимость:
   pip install openpyxl

2. Распакуйте архив в любую папку и запустите из этой папки:
   python run_koap.py

Дальше следуйте инструкциям интерактивного меню (выбор папки, МТУ, этапов).

## Структура

- run_koap.py            — точка входа
- koap_pkg/
  - config.py            — константы, списки управлений, пути
  - utils.py             — вспомогательные функции (чтение ячеек, суммирование листов и т.д.)
  - filefinder.py        — автопоиск файлов по ключевым словам
  - stage1_koap_pipeline.py — этап 1: чтение «4 надзора» + ГАДН, сохранение
  - stage2_testsym.py    — этап 2: попарное суммирование закладок, итоговые листы
  - stage3_opd.py        — этап 3: показатели административной практики -> шаблон ОПД
  - menu.py              — интерактивное меню
  - runner.py            — оркестрация этапов

Отдельные этапы можно запускать автономно, например:
   python -m koap_pkg.stage1_koap_pipeline <входной_файл> <выходной_файл>
